## Green 与出版结果的区别

论文式(3.19)后明确用忽略低折射率对比波导界面反射的近似 radiation Green，并指向更准确表达式。当前 core 使用 full-layer outgoing Green，保持界面连续及源跳跃；不是逐字照搬该近似。不能把这里 full-layer 的重算宣称是出版图逐点复现，尤其不能把参数复现与预测值验证混为一谈。无作者原始数表/可核验数字化曲线，未进行出版曲线误差认证。

证据层级：

1. **来源参数复现**：上表、FF/材料/周期及明确坐标/几何。
2. **独立数学/物理门槛**：现有 `test_waveguide.py` 解析 slab/ODE 与整轴归一化，`test_greens_layered.py` 独立接口/Wronskian/跳跃测试，`test_assembly.py` 任意复场 telescoping 闭合和 cubic manufactured 二阶精度，`test_eigensolver.py` 与小规模 dense 广义本征对照；不是只用同一 solver 比较自己。
3. **数值重算与轴向收敛证据**：下述15次实际求解与复杂场导出。
4. **尚缺**：出版曲线逐点预测验证、真实器件实验验证和完整低阈值竞争谱认证。

共同shift定义为 trace(C)/4 的变化（不是重新拟合参考频率），虚部变化仅舍入量级；去shift后比较 lambda-mean(lambda)，反映splitting而非绝对频移。末步 deltaC 范数2.48720e-3，最大元素差1.16679e-3；C1D、Crad在各D间完全相同，变化来自C2D（自身末步相对差1.42803e-2）。**Crad不随D变化不意味着alpha也不变化**：C2D改变本征矢，辐射阈值仍有上述变化。q控制的最大eig/alpha绝对差分别2.502e-16/2.359e-16，F控制分别4.074e-15/4.510e-16。

结论：高D敏感度以共同实频移为主，splitting和无限域辐射alpha较弱且呈减小趋势；但末步矩阵7.81e-3、去shift谱1.57e-3、alpha集合1.36e-3 **均未达到1e-3相邻相对门槛**。不能宣称完整矩阵、绝对频率或全谱收敛；即便相邻差达标也不等于严格尾误差界。alpha最大绝对相邻差小于1e-4 um^-1可作为这个明确指标的局部稳定证据，不是有限器件最低阈值/实验/出版曲线认证。版本仍为预发布，完整高D有限域竞争谱与出版曲线认证未完成。
